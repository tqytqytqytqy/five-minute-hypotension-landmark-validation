Aggregate source data for the five-minute landmark model submission

These comma-separated-value files contain only aggregate, non-patient-level
results used to reproduce the manuscript tables and figures. No INSPIRE or
MOVER patient-level data are redistributed. Access to the source databases
remains governed by their respective data-use agreements.

The labels in Figure1_source_cohort_timeline_workflow.csv and
Table1_case_mix.csv were updated for clinical clarity in manuscript build 3.0;
the underlying counts and estimates were not changed.

Figure PDFs and PNG previews were generated programmatically from these source
files. The frozen model and analysis-code release is cited in the manuscript.
